Privacy Policy

Ayurix Live Banner ("the app") is a personal tool that updates the banner of the Ayurix YouTube channel with its current subscriber count. About the app. Last updated: 27 October 2026.

Who uses the app

Only the owner of the Ayurix channel. The app does not have other users and does not collect data from visitors or viewers of the channel.

Google user data the app accesses

When the channel owner signs in with Google, the app requests the YouTube scope (https://www.googleapis.com/auth/youtube). With it, the app:

  • reads the channel's subscriber count;
  • reads the channel's existing branding settings, so they are preserved when the banner is changed;
  • uploads a banner image and sets it as the channel banner.

The app does not access videos, comments, playlists, analytics, or any other Google account data.

How data is stored

  • The Google OAuth credentials (client ID, client secret and refresh token) are stored as encrypted secrets in the owner's private GitHub Actions settings. They are not published.
  • The app stores one number, the most recent subscriber count, in a file in its public GitHub repository. This number is already public on the channel.
  • No other Google user data is stored.

Sharing

The app does not sell, share, transfer or disclose Google user data to anyone. It has no advertising, analytics or tracking.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The channel owner can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the repository's secrets removes the stored credentials.
